# Haochen Yang — Academic Homepage

Source for [elias-yang.github.io](https://elias-yang.github.io), built with the [al-folio](https://github.com/alshedivat/al-folio) academic website starter.

## Content

- About and research overview
- Publications sourced from the public Google Scholar profile
- Selected research projects
- CV / experience summary
- Contact and professional profiles

## Local development

Follow the al-folio setup instructions in [`docs/INSTALL.md`](docs/INSTALL.md). The production site is built and deployed by GitHub Actions on pushes to `main`.

## Updating profile information

- Site metadata: `_config.yml`
- Biography and sections: `_pages/`
- Publications: `_bibliography/papers.bib`
- Project summaries: `_projects/`
- Professional links: `_data/socials.yml`
- Profile image: `assets/img/prof_pic.jpg`
